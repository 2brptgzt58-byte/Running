# 러닝 코칭 PWA v7.2

기존 사이트의 파일 전체를 덮어쓰고 앱을 다시 연다. 저장 키를 유지하므로 동일 주소의 기존 기록과 설정을 보존한다. 기존 사용자의 대회 모드는 기본적으로 꺼진다. 먼저 JSON 백업을 권장한다.

## 운동 능력과 발전
- 설정에서 VDOT, 젖산역치 심박, 5km·10km 기록을 수동으로 저장한다. 훈련 기록 추가로 이 수치가 갱신되거나 만료되지 않는다.
- 수동 VDOT가 기본 페이스 기준이다. 없으면 수동 5km·10km 기록의 Daniels–Gilbert 추정치 중 낮은 값을 쓴다. 10km 기록이 더 낮은 능력을 나타내면 역치 페이스를, 5km 기록이 더 낮으면 인터벌 페이스를 보수적으로 제한한다. 높은 기록으로 수동 VDOT를 올리지는 않는다.
- 페이스는 공개 수식 근사치이며 공식 V.O2 표와 같지 않다. 심박은 입력한 역치의 비율로 계산한 보조 가이드다.
- 최근 4개 완료 주 수행량과 회복이 안정적이면 주간 시간을 최대 5% 늘린다. 같은 유형의 최근 2회 품질훈련이 여유 있게 완료되고 회복이 좋으면 역치 반복은 2분, 인터벌은 1회씩 증가시키되 거리·시간 상한을 먼저 적용한다. 롱런 상한도 수행·회복에 따라 조절한다. 숫자 증가는 안전을 보장하는 법칙이 아니다.

## 모드
- 일반 모드: 등록한 대회 날짜·목표는 훈련에 영향을 주지 않는다. 하프 적응을 의무 기준으로 삼지 않는다.
- 대회 저장 후 일정 조정 질문에 확인하면 대회 모드로 전환한다. 취소하면 대회 정보만 저장한다. 설정의 대회 모드 스위치로 해제·재적용한다.
- 대회 모드: 5/10km 준비에서는 현재 능력의 I 페이스 인터벌을 조건부 사용한다. 하프/풀은 현재 능력을 넘지 않는 대회 페이스 반복을 사용한다. 충분한 기록·주간 시간이 있어야 품질훈련을 처방한다.
- 테이퍼 기간은 5/10km 7일, 하프 14일, 풀 21일. 마지막 7일은 평소 시간 예산의 50%, 그 전 테이퍼 기간은 75%. 전 이틀은 휴식, 당일 대회, 이후 첫 주 회복. 개인별 전문 대회 계획의 대체재는 아니다.
- 통증·피로·운동 공백·위험 날씨에 따른 감량은 두 모드 모두 유지한다.

## 목표 추정
표시된 퍼센트는 실제 성공률 데이터로 보정되지 않은 모형 추정치다. 입력 능력과 목표에 필요한 VDOT 차이에 로지스틱 함수를 적용하고 5% 단위, 5~95%로 표시한다. 차이 0에서 50%, 척도 2.5 VDOT다. 코스·날씨·장거리 내구력·향후 향상은 포함하지 않으며, 계획 생성에는 사용하지 않는다. 이를 검증된 개인 성공 확률로 해석하면 안 된다.

## 입력 화면
대회 종목은 5km/10km/하프/풀. 대회 목표와 훈련 총시간은 시간·분 네이티브 선택창이다. iOS에서는 시스템 숫자 선택 UI가 열린다. 기존 훈련의 소수 분은 시간 선택을 바꾸지 않는 편집에서 그대로 보존한다. 5/10km 능력 기록은 분·초다. 오늘 통증은 상태 카드, 운동 시각은 날씨 카드로 이동했다.

## 검증
Node 실행으로 일반 모드 대회 독립성, VDOT별 처방 페이스, 기록별 페이스 제한, 역치 심박 반영, 통증 제한, 4종목 테이퍼, 전날/당일/회복을 검증했다. 저장 이벤트를 실행해 능력 저장, 대회 확인/취소/해제, 시간 변환, 재로드를 확인했다. DOM ID와 JavaScript 문법을 검사했다. 브라우저 다운로드가 네트워크 시간 초과로 실패해 실제 Safari 탭/휠 동작과 화면은 미검증이다.

## v7.1 버그 수정
- CSS의 hidden 우선순위를 보장해 대회 미사용·숨김 입력 영역이 표시되는 문제 수정.
- 존재하지 않는 날짜, 0분·음수·비정상 숫자, 총량보다 큰 본운동을 저장하지 않도록 검증. Enter 제출도 동일 저장 경로 사용.
- 저장 실패 시 입력 유지. 백업 전체 검증 후 복원하고 저장 실패 시 이전 값으로 롤백.
- 대회 후 8일 이후에도 본운동이 10분으로 제한되던 오류 수정. 5/10km의 8~14일 구간에 불필요하게 적용되던 본운동 테이퍼 제거.
- 세션별 시간 상한을 함께 적용해 남은 하루에 주간 예산이 몰리지 않도록 수정. 마지막 주도 능력·이력 조건을 충족해야 품질훈련 가능.
- 지난주 수동 완료한 품질훈련도 주 경계에서 반영. 기록 없이 완료한 세션의 예상 부하도 차감.
- 오늘의 코칭과 주간 일정의 오늘 유형을 일치시킴. 펼침 영역 높이를 관찰해 내용 잘림 방지.
- 분·초 반올림 시 60초가 되는 오류 수정. 기존 소수 분 기록은 메모만 편집하면 보존.

검증 상세는 AUDIT.md, 재실행 스크립트는 tests/에 포함.

## v7.2 코칭 근거 검증
- 일반 모드에서도 충분한 이력과 최근 2회 품질훈련의 양호한 수행·회복이 확인되면 역치 반복과 인터벌을 번갈아 선택한다. 품질훈련일을 추가하지 않는다. 이 선택 주기는 앱 운영 규칙이며 V.O2 공식 스케줄은 아니다.
- I 페이스는 현재 능력으로 정하며 목표 기록으로 늦추거나 가속하지 않는다.
- 인터벌 3분 + 사이 2분 조깅. 최초 3회, 같은 유형의 최근 2회 성공 때 최대 1회 증가, 최대 6회. 본운동은 최근 완료 4주 평균 거리의 8%와 10km 중 작은 값 이내. 시간에 맞지 않으면 횟수를 줄이고 최소 3회가 안 되면 역치 또는 이지로 대체한다. 테이퍼에는 I 인터벌을 새로 넣지 않는다.
- 워밍업 10분, 쿨다운 최소 10분을 포함해 반복·회복 합계가 총시간과 일치한다.
- 역치/대회 페이스 반복에도 최근 주간 거리의 10%라는 보수적 본운동 상한을 적용한다.
- iOS 입력 확대를 유발할 수 있는 select의 14px 상속을 제거하고 16px을 유지한다.
- IPHONE-COACHING-AUDIT.md에 조건별 결과와 실제 기기 미검증 범위를 기록했다.
