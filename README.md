# 러닝 코칭 PWA v6

VDOT 기반 페이스와 실제 수행량 기반 운동시간을 결합한 개인용 하프마라톤 코칭 앱.

## 업데이트
기존 v2 기록·컨디션·설정·주간 체크 저장 키를 유지한다. 동일한 사이트 주소에서 파일 전체를 덮어쓴다. 앱을 삭제하거나 브라우저 데이터를 지우지 않는다. 먼저 기존 앱에서 JSON 백업을 권장한다. 새 coach.js도 반드시 함께 올린다. 서비스워커 캐시 버전은 v6이다.

## 사용
- 훈련 기록에 실제 대회 또는 타임트라이얼을 추가하고 '현재 능력을 보여주는 기록'을 선택하면 최근 90일의 최신 적격 기록으로 VDOT가 갱신된다. 일반 러닝과 목표 기록은 VDOT 계산에 사용하지 않는다.
- 기존 기록을 편집해서 해당 항목을 선택할 수 있다. 총 시간에는 대회·타임트라이얼 본 기록만 입력한다.
- 설정에서 현재 VDOT와 기준 날짜를 직접 입력할 수도 있다. 최신 기준 날짜가 우선이다. 가민 VO2max를 그대로 입력하지 않는다.
- VDOT 훈련 페이스는 공개 Daniels–Gilbert 수식과 강도 비율을 이용한 근사값이다. 공식 V.O2 표·공식 서비스와 동일하다고 보장하지 않는다. 역치·인터벌 값은 참고값이고 현재 자동 품질 처방은 역치와 하프페이스 중심이다.
- 본운동 시간·거리·반복·회복 및 수행 결과와 다음 날 회복을 입력한다. 최근 두 품질훈련의 수행·회복이 좋으면 본운동 시간을 소폭 늘린다. 이를 VDOT 상승으로 간주하지 않는다.
- 오늘 컨디션을 입력한다. 설정의 오늘 통증 반응에서 보행 통증·점 압통·악화를 표시할 수 있다.
- 운동 예정 시각 기본값은 20시. 해당 시각의 시간별 예보를 사용하고 없으면 날씨 미확인을 표시한다.

## 코칭 규칙
- 최근 네 개 완료 주의 실제 시간을 기반으로 주간 예산을 만들고 남은 세션에 배분한다. 세 주 이상 충분히 기록되고 회복이 안정적이면 5% 증가를 허용한다. 이는 앱 운영 정책이며 보편적인 안전선은 아니다.
- 기록이 부족하면 임시 저강도 계획. 자료 부족과 실제 운동 공백을 구분할 수 없으므로 누락 기록을 입력해야 한다.
- 충분한 시간·RPE 자료가 있으면 예정 세션의 예상 RPE까지 합쳐 부하를 사전 제한한다. 1.35를 부상 예측 임계값으로 사용하지 않는다.
- 롱런은 최근 30일 최장거리, 다음 날 회복과 장기 공백으로 제한. 회복 확인 때 최대 8% 증가를 허용하지만 안전 보장은 아니다.
- 대회 2주 이내 주간 시간 축소. 대회 전 이틀은 휴식, 당일은 레이스, 이후 첫 주는 회복. 하프 외 거리의 특이훈련은 지원하지 않는다.
- 통증 위험과 위험 날씨가 대회보다 우선. 평범한 비만으로 취소하지 않는다. 체감온도는 WBGT가 아니며 낙뢰의 실시간 위치·대기질을 수집하지 않는다.
- 강도 비중은 세션 기준 참고값. 80/20 비율만으로 품질훈련을 추가·취소하지 않는다.
- 최대 심박·역치 측정 없이 LT1을 판정할 수 없으므로 심박 범위는 보조 가이드다. 대화·RPE와 컨디션 우선.

## 검증 및 한계
Node에서 대회 전날·당일, 위험 통증, 고온, 운동 공백, VDOT 적격·만료·미래 기록, 페이스 반올림, 훈련 분류, 예산 및 페이스 변화 등 16개 조건을 검증했다. HTML ID 연결과 JavaScript 문법을 확인했다. 이 실행 환경에 브라우저 실행 파일이 없어 실제 Safari/모바일 화면 검증은 하지 못했다.
