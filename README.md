# 러닝 코칭 PWA v2

맥 없이 iPhone에서 사용할 수 있도록 기존 SwiftUI 2차 버전을 PWA(홈 화면 웹앱)로 전환한 버전입니다.

## 포함 기능
- 앱 이름: **러닝 코칭**
- 2026-10-25 하프마라톤 1:50 목표
- Garmin Connect 기록 수동 입력
- 거리 + 시간 → 평균 페이스 자동 계산
- 페이스 + 케이던스 → 1보당 이동거리 자동 계산
- 평균/최대 심박, 케이던스, 접지시간, 수직진폭, RPE, 통증, 신발, 메모
- 최근 7일 / 이전 7일 / 최근 28일 훈련량 분석
- 최근 롱런 및 품질훈련 강도 반영
- 전주 대비 급증, 48시간 내 고강도, 최근 통증 감지
- 청도 이서면 인근 Open-Meteo 날씨 반영
- 우천 회피, 고온·고습 시 거리/페이스 자동 조정
- 오프라인 앱 셸 캐시
- 기록 JSON 백업/복원

## iPhone에 설치하는 방법
PWA는 **HTTPS 웹주소에 올려야** iPhone에서 정상적인 앱처럼 설치할 수 있습니다.

가장 쉬운 방법 중 하나:
1. 이 폴더의 파일 전체를 GitHub 저장소에 업로드
2. GitHub Pages 활성화
3. 생성된 HTTPS 주소를 iPhone Safari에서 열기
4. Safari 공유 버튼 → **홈 화면에 추가**
5. 홈 화면의 `러닝 코칭` 아이콘으로 실행

Netlify, Cloudflare Pages 같은 정적 호스팅에도 그대로 올릴 수 있습니다.

## 중요한 차이
- 기록은 브라우저의 localStorage에 저장됩니다. Safari 사이트 데이터를 지우면 기록도 삭제될 수 있으므로 `설정 → 기록 JSON 백업`을 가끔 사용하세요.
- 날씨를 불러오려면 인터넷 연결이 필요합니다. 앱 UI와 기존 기록은 오프라인에서도 열립니다.
- iPhone PWA에서 **매일 특정 시각에 자체적으로 예약 알림을 생성하는 기능은 일반 웹 API만으로는 구현할 수 없습니다.** Web Push용 서버가 필요합니다. 이번 버전에서는 넣지 않았습니다.
- 현재 날씨 위치는 기존 앱과 동일하게 청도 이서면 인근 좌표(35.66, 128.67)를 사용하며 정확한 주소는 저장하지 않습니다.

## 로컬 테스트
PC에서 폴더를 연 뒤 단순 파일 더블클릭보다 HTTP 서버로 실행하는 것이 좋습니다.

Python이 있다면:
`python -m http.server 8000`

그 뒤 브라우저에서:
`http://localhost:8000`

서비스 워커/PWA 설치 기능은 실제 iPhone에서는 HTTPS 호스팅에서 사용하세요.
