# 러닝 코칭 PWA v4

개인 러닝 코칭용 PWA.

## v3 주요 변경
- 훈련 기록 편집 버튼 추가
- 훈련 카드 터치 시 앱 자체 분석
- 메인 상단의 고정 대회 정보 제거, 목표 대회는 설정에서 선택 사용
- `최근 훈련 부하`를 `마일리지`로 변경
- 오늘 시간대별 날씨 가로 스크롤 표시
- 오늘의 코칭 카드를 딥블루 계열로 강조
- `Why?` 설명으로 변경, 설명 텍스트 색상 통일 및 핵심만 볼드
- 오늘 컨디션 UI를 선택형으로 개편
- 피로/근육통/통증 0~10, 수면 5단계
- 통증 1 이상 시 부위 + 좌우 + 메모 기록
- 날짜별 컨디션/통증 이력 저장 및 동일 부위 상승 추세 코칭 반영
- JSON 백업에 훈련/컨디션/대회 설정 모두 포함
- 네이비 러너 앱 아이콘 및 새 서비스워커 캐시

## GitHub Pages 업데이트
저장소 루트의 `index.html`, `styles.css`, `app.js`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`를 이 버전 파일로 교체하면 됩니다.

기존 훈련 기록은 `runningCoaching.runRecords.v2` 저장키를 유지해 그대로 이어서 사용합니다.
