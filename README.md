# 러닝 코칭 PWA v9.0

기존 사이트의 파일을 전체 교체한다. 같은 주소에서는 기존 기록·대회 설정을 유지한다. 데이터 관리에서 v9.0을 확인한다. 배포 전에 JSON 백업을 내려받을 수 있다.

## 처음 시작

설정 → 현재 운동 능력에 최근 실력을 대표하는 5km 또는 10km 기록을 분·초로 입력하고 저장한다. 한 기록만 있어도 된다. 두 기록이 있으면 계산된 VDOT 중 낮은 값을 훈련 기준으로 사용한다. 서로 다른 시기나 조건의 기록이라면 현재 실력을 대표하도록 직접 수정한다. 10km 50분은 약 VDOT 40이다.

VDOT 직접 입력은 제거했다. 이전 수동 VDOT가 남아 있어도 코칭에 사용하지 않는다. 기존 5km·10km 입력 기록은 유지된다. 일상 훈련 기록으로 VDOT가 올라가거나 기록이 자동 만료되지 않는다. 젖산역치 심박은 심박 참고 범위에만 사용하며 페이스 계산은 기록 기반이다.

실제 훈련 기록이 없어도 기본 주 3회·총 75분의 이지 중심 계획으로 시작한다. 선택 항목 ‘훈련 시작 기준’에서 평소 주간 거리와 주 3/4/5회 빈도를 저장할 수 있다. 선언한 거리는 처음에 km당 6분으로 환산하는 임시 운동량 기준이다. 체력 검사나 검증된 개인 예측값이 아니다. 최근의 충분한 훈련 기록이 쌓이면 실제 수행 시간을 기준으로 삼는다. 오늘 상태를 입력하지 않으면 25분 이내 임시 회복안이 나온다.

## 훈련 흐름

- 최초 사용 주부터 4주 단위 기초·발전·회복 주기를 유지한다. 앞으로 4주의 훈련 방향을 표시하며 상세 처방은 당일 상태와 수행 기록에 맞춰 정한다.
- 확인된 수행량과 양호한 회복이 있을 때 주기 내 3%·6%의 제한적인 증가를 허용한다. 회복 주간은 20% 감량한다. 이 수치는 앱 운영 정책이며 보편적으로 검증된 부상 예방 수치가 아니다.
- 회복 주간을 다음 블록의 평상시 운동량 기준에서 제외한다. 운동시간과 sRPE 제한은 공통 배율로 적용하며 감소 요인을 연속 곱하지 않는다. 실제 수행량보다 무조건 늘리지는 않는다.
- 지난주 기록이 부족하면 미확인으로 취급한다. ‘기록 누락 있음’으로 명시할 수도 있다. 실제 쉬었다면 ‘지난주 러닝하지 않음’을 선택한다. 기록이 없다는 이유만으로 장기간 중단으로 간주하지 않는다. 설정한 횟수만큼 기록이 있거나 사용자가 입력 완료로 확인한 주를 확인된 주로 사용한다.
- 인터벌은 현재 능력의 I 페이스, 기본 3분 × 3회·사이 2분 조깅이다. 주간 거리 8% 및 세션 시간 상한을 적용한다. 역치 본운동은 주간 거리 10% 상한을 적용한다. 준비·정리운동을 포함하며 최소 조건을 충족하지 못하면 이지런으로 대체한다.
- 같은 페이스에서 성공적으로 수행한 본운동 기록과 다음 날 회복이 있어야 반복량 증가가 가능하다. VDOT 변경만으로 반복 수도 함께 증가하지 않는다.

## 대회와 화면

대회 저장과 훈련 모드를 분리했다. 대회 편집 후 일정 변경을 확인해야 대회 모드가 된다. 일반 모드는 등록한 대회의 영향을 받지 않는다. 대회 모드에서는 ‘오늘의 코칭(대회)’와 선택 상태로 구분한다.

5km는 인터벌, 10km는 역치·인터벌, 하프는 역치·지속력, 풀은 장거리 지속력·대회 페이스를 중심으로 한다. 5/10km는 마지막 7일, 하프 14일, 풀 21일의 조절 기간을 둔다. 기간 초반은 약 25%, 마지막 7일은 약 50% 감량한다. 테이퍼 이전 기준량을 고정해 반복 감량을 막는다. 대회 전날·당일·이후 첫 주를 별도로 처리한다. 감량·회복·통증 조건이 거리별 초점보다 우선한다.

목표 달성률을 임의의 확률로 표시하지 않는다. 현재 기록의 등가 환산 시간과 목표 차이를 표시한다. 장거리 환산은 실제 지구력·보급·날씨를 보장하지 않는다.

능력 설정, 대회 요약·편집, 오늘 상태, 날씨 시각을 분리했다. 날짜 입력을 단독 행으로 두고 시간 입력은 네이티브 선택칸을 사용한다. 인접 탭은 노출하지 않는다.

## 근거와 한계

- V.O2 공식 훈련 정의: https://vdoto2.com/learn-more/training-definitions
- 테이퍼 메타분석: https://pubmed.ncbi.nlm.nih.gov/37163550/

VDOT·훈련 페이스는 공개 수식의 근사치이며 공식 V.O2 표와 차이가 있을 수 있다. VDOT는 장치의 VO₂max와 다르다. 4주 주기, 시작 운동량, 거리별 준비 기간 및 증감계수는 위 근거를 참고한 앱 정책이다. 개인 사용 데이터가 없는 상태에서 효과나 부상 위험 예측을 검증한 것은 아니다.

## 검증

Node VM 기반 16주 연속 사용 시뮬레이션, 528개 거리·모드·능력 조합, 512개 코칭 조건, 720개 품질훈련 구성 조건을 검사한다. VDOT 변경, 저장·재실행, 대회 확인/취소, 날짜, 백업 복원 실패의 롤백, 한국 시간 자정, 서비스워커 캐시 업그레이드·오프라인 경로도 검사한다.

실행: `TZ=Asia/Seoul node tests/run-all.cjs`

실제 iPhone Safari/PWA의 화면 렌더링·터치·키보드는 실행 검증하지 못했다. 코드 모형 검증은 기기 테스트를 대체하지 않는다.
