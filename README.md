# 러닝 코칭 PWA v5

개인용 러닝 코칭 PWA. 기존 v4 데이터(localStorage)를 그대로 이어서 사용한다.

## v5 핵심 변경

- 오늘의 코칭 6칸: 거리 / 페이스 / 심박 / RPE / 워밍업 / 쿨다운
- `이번 주 러닝` 카드 추가
  - 오늘·지난 날짜를 눌러 `완료 / 미실시 / 미정` 체크
  - 실제 훈련 기록이 있으면 자동으로 완료로 인식
  - 미실시한 이지·품질·롱런을 무조건 복사하지 않고 남은 요일에 안전하게 재배치
  - 예: 화 이지 미실시 → 수 이지 이동 가능 / 목 품질 유지
  - 예: 목 품질 미실시 → 금 품질 + 토 휴식 + 일 롱런으로 이동 가능
- 실제 수행 여부를 다음날 코칭에 반영
- 좌우 탭 전환을 손가락 추종형 스와이프로 개선
- 훈련강도 분포(TID) 관리
  - 최근 28일 `세션 목표 방식(session-goal method)`을 주 지표로 사용
  - 저강도 세션 약 80%를 중심값으로 하되 75–85%를 실전 허용 범위로 사용
  - 시간 기준 저강도 비중도 함께 계산해 보조 지표로 표시
  - 저강도 비중이 낮으면 향후 품질훈련을 이지로 낮추고, 높으면 회복 상태가 좋을 때 주 1회 품질훈련을 유지
  - 통증·피로·수면·최근 강한 훈련 등 안전 신호가 80/20 목표보다 항상 우선
- session-RPE(운동시간 × RPE)를 개인 내부부하의 보조 지표로 사용
  - 과거 3주 개인 기준보다 최근 7일 부하가 크게 높을 때만 소프트 경고
  - 특정 숫자를 부상 예측 임계값으로 사용하지 않음
- JSON 백업에 주간 수행 체크도 포함

## 강도 분포 해석

`80/20`은 정확히 80.0%를 맞춰야 하는 생물학적 법칙이 아니다. 연구에서는 저강도 비중을 세션 수, 시간, 심박, 젖산 등 서로 다른 방식으로 계산하며 결과가 달라질 수 있다. 이 앱은 사용 편의성과 주간 계획 조정을 위해 **세션 목표 방식의 75–85% 저강도 범위**를 주 제어값으로 사용하고, 실제 러닝 시간 기준 저강도 비중을 보조로 보여준다.

이지·회복·대부분의 롱런은 저강도로 분류하지만, 이지로 기록했더라도 RPE가 매우 높거나 평균심박이 높은 경우에는 저강도 세션으로 100% 인정하지 않는다. 템포·하프페이스·인터벌은 품질 세션으로 분류한다.
